# 2026-07-26 工作日志

## 废品行情通 PWA 应用开发

### 完成内容
为废品回收站老板打造了完整的废品回收价格查询 PWA 应用。核心策略：手机端内置爬虫 + 本地 IndexedDB 存储 + 离线可用，零服务器成本。

### 技术选型决策
- 用户需求文档指定 Flutter，但环境无 Flutter SDK，且用户爸爸（50多岁非技术背景）需要立刻可用
- 最终选择 **PWA（渐进式 Web 应用）** 方案：任何手机浏览器即可打开、可安装到桌面、完全离线可用
- 数据库用 IndexedDB 替代 SQLite，Service Worker 实现离线缓存
- 爬虫通过 CORS 代理（allorigins/corsproxy/codetabs 三代理轮换）适配浏览器环境，真实爬取失败时自动切换模拟数据更新

### 项目文件
- `index.html` - 4 Tab 主页面（行情/记账/趋势/我的）
- `css/style.css` - 大字体(20/28px)、红涨绿跌、暗色模式
- `js/db.js` - IndexedDB 封装（8个表）
- `js/seed-data.js` - 30+品类 + 90天种子价格
- `js/crawler.js` - 爬虫引擎（定时/WiFi检测/电量检测/失败重试/模拟后备）
- `js/charts.js` - Chart.js 趋势图（7/30/90天 + 双品类对比）
- `js/export.js` - JSON/Excel 导出导入
- `js/app.js` - 主逻辑（Tab切换/搜索筛选/收藏/弹窗/记账）
- `manifest.json` + `sw.js` - PWA 离线支持
- `data/crawler-rules.json` - 爬虫规则配置

### 注意事项
- crawler-rules.json 不能含 JS 注释（`/**/`），已改用 `_comment` 字段
- Chart.js 通过 CDN 引入，Service Worker 首次访问时缓存以支持离线
- 爬虫模拟更新逻辑确保即使 CORS 代理全部失败，App 仍能展示"新鲜"数据

### Bug 修复

- 修复方案：去掉 `!important`，改用 `.hidden` 类控制显隐；HTML 默认加 `hidden` 类；JS 用 `classList.add/remove('hidden')`
