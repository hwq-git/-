# 2026-07-28 工作日志

## 修复：初始化失败（renderSettings null 元素）

### 问题
- 用户修改了 index.html 设置页，删掉了"仅WiFi更新"设置项（`setting-wifi-only`）
- 但 `app.js` 的 `renderSettings()` 仍硬编码访问 `document.getElementById('setting-wifi-only').checked`
- 元素不存在 → `Cannot set properties of null (setting 'checked')` → 整个 `init()` catch 分支触发
- 导致后续 `Crawler.startScheduler()`、`registerSW()`、`fillCategorySelects()` 全部被跳过

### 修复
- `js/app.js` renderSettings()：三个 DOM 赋值全部加 null 检查（`if (el) el.checked = ...`）
- 这样以后再改 HTML 删设置项也不会崩

### 注意
- 控制台 `stadium.js` 报错是浏览器扩展注入的，非项目文件，可忽略
- 用户当前 crawler-rules.json 为 v2.0.0，仅 1 个站点（金投网-废金属行情），JSON 加载正常
- 设置页缺少"站点认证"入口按钮（之前用户抱怨认证弹窗点不开的根因之一）

## 修复：浏览器加载旧缓存代码 → SyntaxError

### 问题
- 用户报 `Uncaught SyntaxError: Unexpected token 'async' (at app.js:434:3)`
- Node.js `--check` 语法检查通过，服务器返回最新代码也是正确的
- 根因：Service Worker 缓存了旧版 `app.js`（`CACHE_NAME = feipin-v1.0.2`），fetch 拦截返回缓存副本
- 旧版 app.js 第 434 行有语法错误，但新版已修复——浏览器永远看不到新代码
- 附带问题：SW 尝试缓存 `chrome-extension://` 请求，报 `scheme 'chrome-extension' is unsupported`

### 修复
1. `sw.js`：CACHE_NAME 升级为 `feipin-v1.0.3`，激活时自动清除旧缓存
2. `sw.js`：fetch 处理器新增 `if (!url.protocol.startsWith('http')) return;` 跳过扩展请求
3. `sw.js`：移除重复的 `const url` 声明
4. `index.html`：所有 `<script>` 标签加 `?v=1.0.3` 缓存破坏参数

### 后期建议
- 每次修改 JS/CSS 后同时升级 SW CACHE_NAME + HTML 版本参数
- 开发阶段可在浏览器 DevTools → Application → Service Workers 勾选 "Update on reload"

## 新增：前端标记模拟数据 vs 真实数据

### 背景
- 用户加了 Python 爬虫 `scripts/scraper.py`，独立运行产出 `data/scraped-prices.json`
- Python 爬虫抓取金投网 API（7个废金属品类真实数据），缺失品类用模拟补齐（23个品类）
- scraped-prices.json 里每条价格有 `sources` 字段（如 `['金投网']` 真实 vs `['行情参考价（模拟）']` 模拟）和 `sample_count`（真实>1，模拟=1）
- 但前端 `fetchRemotePrices()` 读取时**完全忽略这些字段**，全部标记为 `source: 'crawler'`
- `simulatePriceUpdate()` 也用 `source: 'crawler'`，用户无法区分

### 修复（4处改动）
1. `js/crawler.js` fetchRemotePrices()：解析 `sources` 和 `sample_count` 字段
   - 真实数据 → `source: 'crawler'`, `source_detail: '金投网 · 152样本'`
   - 模拟数据 → `source: 'simulated'`, `source_detail: '行情参考价（模拟）'`
2. `js/crawler.js` simulatePriceUpdate()：`source: 'crawler'` → `source: 'simulated'`
3. `js/app.js` sourceMap：新增 `simulated: { tag: '📊', label: '模拟', class: 'simulated' }`
4. `css/style.css`：新增 `.source-tag.simulated` 橙色样式（区别于蓝色真实爬虫）
5. `js/app.js` renderCrawlerStatus()：设置页统计分"真实行情"和"模拟行情"两行
6. SW 缓存升级 v1.0.4 + HTML 脚本标签版本号同步

### 项目架构总结
- **Python 爬虫**：独立运行（`python scripts/scraper.py`），一次性产出 JSON 文件，不是常驻服务
- **前端**：通过 HTTP fetch 读取 `scraped-prices.json`，读取失败则回退到浏览器端模拟
- **数据流**：scraper.py → scraped-prices.json → crawler.js fetchRemotePrices() → IndexedDB → app.js 渲染
